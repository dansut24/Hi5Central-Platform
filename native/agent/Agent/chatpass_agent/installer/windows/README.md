# Hi5Central Agent Windows Installer

This builds an elevated, machine-wide Windows installer for the Hi5Central Agent.

## Install behaviour

- Requires administrator rights.
- Installs to `C:\Program Files\Hi5Central\Agent`.
- Stores config and logs in `C:\ProgramData\Hi5Central\Agent`.
- Installs and starts the Windows service `Hi5CentralAgent`.
- Preserves existing device enrolment and `config.ini`/`secrets.dat` when upgrading.
- `UsePreviousAppDir=no` prevents inherited Hi5Tech paths; the agent always installs under `C:\Program Files\Hi5Central\Agent`.
- Stops/removes the service on uninstall.

## Build

From the `chatpass_agent` folder:

```powershell
.\installer\windows\Build-AgentInstaller.ps1 -InnoSetupCompiler "C:\Program Files (x86)\Inno Setup 6\ISCC.exe"
```

Output:

```text
dist\installer\Hi5CentralAgentSetup.exe
```

## Manual install

```powershell
Start-Process ".\Hi5CentralAgentSetup.exe" -Verb RunAs -Wait
```

## Silent install with enrolment data

```powershell
Start-Process ".\Hi5CentralAgentSetup.exe" -Verb RunAs -Wait -ArgumentList @(
  '/VERYSILENT',
  '/NORESTART',
  '/SUPPRESSMSGBOXES',
  '/API_BASE_URL="https://app.hi5central.com"',
  '/AGENT_WS_BASE_URL="wss://rmm.hi5central.com/agent/ws"',
  '/ENROLLMENT_TOKEN="YOUR_ENROLLMENT_TOKEN"',
  '/TENANT_ID="TENANT_ID_HERE"',
  '/GROUP_ID="GROUP_ID_HERE"',
  '/PACKAGE_ID="WINDOWS_X64_DEFAULT"',
  '/INSTALL_SOURCE="rmm-portal"'
)
```

## Forward-compatible enrolment option

The installer also accepts:

```text
/PROVISION_BLOB="..."
```

Use this later for a signed/base64 JSON payload generated by the platform, for example containing tenant, group, expiry, package id, and policy id.

## Config written by installer

The installer writes values into:

```text
C:\ProgramData\Hi5Central\Agent\config.ini
```

Example:

```ini
[agent]
api_base_url=https://app.hi5central.com
agent_ws_base_url=wss://rmm.hi5central.com/agent/ws
enrollment_token=...
tenant_id=...
group_id=...
package_id=...
provision_blob=...
install_source=rmm-portal
installer_version=1.0.0
```

The C++ agent already reads this config, calls `/api/devices/enroll`, and sends the enrolment fields to the platform. The returned `device_key` is stored in `secrets.dat` protected with machine-level DPAPI.

## Test after install

```powershell
Get-Service Hi5CentralAgent
Get-Content "C:\ProgramData\Hi5Central\Agent\config.ini"
Get-Content "C:\ProgramData\Hi5Central\Agent\Logs\agent.log" -Tail 100
```
