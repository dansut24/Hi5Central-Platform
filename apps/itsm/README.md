# Hi5Central ITSM

Standalone Hi5Central IT Service Management and browser Self-Service application.

This repository contains:
- Analyst/service-desk workspace
- Incidents, requests, problems, changes and tasks
- Service catalogue
- Knowledge
- Live chat
- Organisation/people views
- Browser requester Self-Service portal
- Onboarding, profile and workspace security UI

Backend APIs and schema migrations are owned by Hi5Central Control Server.
